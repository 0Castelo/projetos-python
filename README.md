Repositório com projetos desenvolvidos para praticar os fundamentos da linguagem Python.


Calculadora

Calculadora interativa com menu de opções no terminal.
Funcionalidades:

Soma, subtração, multiplicação e divisão
Menu de navegação com loop
Proteção contra divisão por zero
Tratamento de entradas inválidas com try/except


Gerenciador de Lista

Programa para gerenciar uma lista de itens no terminal.
Funcionalidades:

Adicionar itens à lista
Visualizar todos os itens com índice numerado
Remover itens pelo número
Validação de entradas inválidas


Par ou Ímpar

Verificador de números pares e ímpares com loop contínuo.
Funcionalidades:

Verifica se o número é par ou ímpar usando o operador módulo %
Loop que repete até o usuário digitar 0 para sair
Tratamento de entradas inválidas



Tecnologias utilizadas

Python 3
Recursos nativos da linguagem (sem bibliotecas externas)
